# Linta

Каркас B2B SaaS-платформы для онлайн-записи и управления студией.

## Запуск

```bash
npm install
npm run dev
```

Приложение будет доступно по адресу [http://localhost:3000](http://localhost:3000).

## Проверки

```bash
npm run lint
npm run build
```

Проект использует Next.js App Router, TypeScript в строгом режиме, Tailwind CSS и Framer Motion.
